# EFT CRM

Текущий выпуск: **версия 34**. Рабочий домен получает защищённый вход и серверную сессию, а основные рабочие разделы сохраняют данные в MySQL. Добавлен раздел логистики для планирования рейсов, транспорта, водителей и окон доставки. GitHub Pages остаётся открытой демоверсией.

Первый интерактивный прототип самостоятельной CRM ЭФТ на React и Vite. Владелец согласовал визуальное направление, и рабочие экраны опубликованы для просмотра на [GitHub Pages](https://svc4p7vc8y-beep.github.io/EFT-CRM/).

## Что можно попробовать

- Создавать заявки, менять этап, ответственного и следующий контакт.
- Открывать карточку клиента и объекта, вести ручную историю звонков, встреч и переписки.
- Передавать согласованную комплектацию в цех как заказ с первым заданием.
- Создавать и обновлять задачи цеха, назначать сотрудника, отмечать объём и пункты проверки.
- В «Настройках» добавлять и редактировать сотрудников, должности и бригады; новые менеджеры доступны для назначения в заявки, сотрудники цеха — в задания.
- Просматривать задачи на доске, в списке и в календаре; фильтровать и искать.
- Выгружать резервную копию в JSON и загружать её обратно.
- Вести табель дней и часов, печатать или выгружать его в CSV.
- Вести закупки, приход и расход материалов, текущий прайс и выдачу инструмента.
- Использовать календарь на неделю, месяц и год, быстро создавать задачи по редактируемым шаблонам и диктовать текст в поддерживаемом браузере.
- Открывать заявку или клиента в отдельной рабочей карточке: видеть прогресс, историю, задачи и вложения, быстро фиксировать общение и планировать следующий шаг из настраиваемого списка.
- Просматривать склад и общий прайс единым прокручиваемым списком без постраничного переключения.
- Собирать отдельные потребности производства и ТП в инструменте, оборудовании и расходных материалах, добавляя несколько ссылок для последующего заказа.
- Вести строительство по объектам: развернуть типовой план из 18 этапов, назначать сроки, сотрудников и бригады, отмечать готовность, задержки, зависимости, комментарии и фотографии.
- Создавать задачи из этапов строительства с уже заполненными объектом, этапом, бригадой, ответственным и сроком.
- Планировать рейсы по объектам и заказам, назначать машину, водителя и перевозчика, фиксировать маршрут, окно доставки и текущий статус.

На GitHub Pages данные демонстрационные и сохраняются **только в браузере этого устройства** через localStorage. Не вводите реальные персональные данные на публичном сайте. Для `crm.eftsip.ru` подготовлены MySQL, одноразовый установщик, вход по паролю, защищённые серверные сессии, роли и журнал действий. Перенос рабочих разделов с локальных данных на сервер выполняется поэтапно. Копии документов сотрудников появятся после закрытого файлового хранилища. Почта и мессенджеры ещё не подключены: раздел общения фиксирует события вручную.

Планирование занятости бригад и логистика уже доступны. Прайс перенесён из калькулятора и доступен для ручного обратного экспорта. Автоматический обмен с EFT SIP Calculator будет подключён после переноса основных рабочих данных в серверную базу.

## Запуск и проверка

Node.js 24:

```bash
npm ci
npm test
npm run dev
```

Для production-сборки: `npm run build`; проверить её локально: `npm run preview`.

Страница с утверждёнными визуальными концепциями: [дизайн](https://svc4p7vc8y-beep.github.io/EFT-CRM/?view=design). CI проверяет тесты и сборку; каждый push в `main` публикует GitHub Pages. Ресурсы используют относительные пути для подкаталога Pages и будущего поддомена.
