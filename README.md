# EFT CRM

Самостоятельная система ЭФТ для клиентов, заявок, цеха и строительства. React + Vite.

Сейчас приложение показывает два визуальных макета для первоначального согласования: заявки и задачи цеха. Это страница просмотра концепций, а не рабочая CRM. На изображениях вымышленные примеры. Рабочие экраны реализуются после согласования владельцем.

## Локальный запуск

Node.js 24, затем `npm ci` и `npm run dev`. Production-сборка: `npm run build`; проверка локально: `npm run preview`.

## Предпросмотр

[Открыть страницу](https://svc4p7vc8y-beep.github.io/EFT-CRM/).

Workflow `pages.yml` проверяет сборку в pull request и публикует main в GitHub Pages после каждого push. В Settings → Pages используется GitHub Actions. На странице отображается короткая ревизия сборки. Ресурсы используют относительные пути для подкаталога GitHub Pages и будущего поддомена.

Публикация на Beget — отдельный будущий этап. Рабочие данные, серверные ключи, почта и база калькулятора к предпросмотру не подключены.
