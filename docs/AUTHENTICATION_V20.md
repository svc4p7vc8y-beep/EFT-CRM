# Версия 20: вход в рабочую CRM

## Два режима одной сборки

- Без `VITE_CRM_API_URL` приложение работает как публичная демоверсия с данными в браузере. Этот режим публикуется на GitHub Pages.
- С `VITE_CRM_API_URL=/api/api.php` приложение сначала проверяет серверную сессию и показывает форму входа. Этот режим предназначен для `crm.eftsip.ru`.

## Реализовано

- отдельный экран входа в стиле ЭФТ;
- вход по логину и паролю через JSON API;
- защищённая cookie сессии и CSRF токен для изменяющих запросов;
- восстановление активной сессии после обновления страницы;
- загрузка серверного контекста пользователя и его прав;
- карточка текущего аккаунта и выход из системы;
- понятные сообщения при недоступности или ошибке сервера.

## Следующий этап

После выпуска HTTPS сертификата одноразовый установщик создаёт таблицы и аккаунт владельца. Затем данные сотрудников и табеля подключаются к готовым API методам вместо локального хранилища.
