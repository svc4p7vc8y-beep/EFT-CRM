# Центр общения — версия 43

## Что реализовано

- единая лента клиента по почте, Telegram, WhatsApp, MAX, звонкам и внутренним заметкам;
- начало диалога с клиентом, у которого ещё нет сообщений;
- ответ на конкретное сообщение и быстрые шаблоны;
- до 8 вложений к сообщению, до 10 МБ каждое и до 25 МБ суммарно;
- защищённое скачивание вложений через авторизованный API CRM;
- статусы «сохранено», «отправлено», «доставлено» и «ошибка»;
- серверная диагностика подключений без передачи токенов в браузер;
- адаптеры отправки для почты, Telegram Bot API и WhatsApp Cloud API;
- сохранение сообщения в CRM, даже если внешний канал ещё не подключён.

## Параметры сервера

Все секреты добавляются только в `api/config.local.php` в секцию `integrations`. Этот файл исключён из Git и из автоматической публикации.

### Почта

Нужны адрес отправителя и имя отправителя. Текущая серверная отправка использует почтовый транспорт хостинга. Для отдельного ящика Mail.ru или VK WorkSpace следующим этапом добавляется SMTP и IMAP синхронизация.

### Telegram

Нужны токен бота и соответствие `siteId → chatId`. Клиент должен сначала открыть диалог с ботом или добавить его в нужный чат.

### WhatsApp

Нужны постоянный access token, Phone Number ID и активный номер WhatsApp Business. Адресат берётся из телефона клиента.

### MAX

Интерфейс и хранение готовы. Для отправки нужен официальный токен бота и идентификаторы чатов после выдачи доступа к Bot API.

## Следующий этап

1. Заполнить серверную конфигурацию без публикации секретов в GitHub.
2. Проверить тестовые отправки в каждый канал.
3. Подключить входящие сообщения: Telegram webhook, WhatsApp webhook, IMAP для почты и webhook MAX.
4. Добавить сопоставление неизвестного отправителя с клиентом и очередь необработанных обращений.
