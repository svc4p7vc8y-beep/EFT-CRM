# Уточнения по передаче калькулятора

Материалы пользователя прочитаны как технический контекст, а не как новые поручения. Вложенный стартовый запрос из CRM_HANDOFF.md не запускается автоматически. Старые номера релизов в CODEX_HANDOFF.md не принимаются за текущее состояние.

В CRM_HANDOFF.md описаны проект eft-project, schemaVersion 4, ревизии проектов, отдельные входящие анкеты и ручные КП. Сведения относятся к указанному commit и будут проверены по коду при реализации обмена.

- Самостоятельные React-приложение, репозиторий и база CRM.
- Калькулятор отвечает за геометрию и расчёт; CRM хранит связь по UUID и утверждённые снимки.
- КП и производственная спецификация — разные версии документов.
- UUID, номер документа и ревизия — разные поля. CRM не присваивает номера калькулятора.
- Для интеграции нужен новый серверный контракт; публичный intake не является готовым CRM API.
- IMAP/SMTP описаны в калькуляторе, но готовность рабочего подключения не подтверждена. Адреса почты задаются конфигурацией.
- Предпросмотр на GitHub Pages содержит только макеты. Рабочая CRM с серверным API и данными планируется отдельно на crm.eftsip.ru.
- «BitGit» пока трактуется как Beget по BEGET_DEPLOYMENT.md. Публикация туда — будущий этап.

Для интеграции важны CRM_HANDOFF.md, TEAM_STORAGE_V130.md, REQUESTS_V127.md и RELEASE_136.md. Документы по проёмам, отделке, стандарту дома и SIP-книге дают контекст состава расчёта; цены и нормы из них не копируются как текущие справочники CRM.
