# Хранение документов сотрудников — требования к серверному этапу

Публичная версия GitHub Pages не принимает файлы документов. Фотографии и сканы не кодируются в localStorage и не включаются в экспорт демонстрационных данных.

Для рабочего модуля нужны:

- Закрытое файловое хранилище без публичных адресов и серверная база метаданных: сотрудник, тип документа, имя файла, версия, дата загрузки, автор и срок актуальности.
- Проверка входа и права для кадровой роли и руководителя; другие сотрудники не получают доступ к сканам по умолчанию.
- Проверка формата и размера файла, безопасная обработка имени, антивирусная проверка до выдачи доступа.
- Шифрование при передаче и хранении, резервные копии и журнал загрузки, просмотра, скачивания и удаления.
- Отдельные правила хранения и удаления по утверждённой политике ЭФТ. Удаление и замена файла должны оставлять событие в журнале.
- Недопущение попадания файлов и содержимого документов в GitHub, сборку фронтенда, браузерный экспорт и логи.

Типы документов и конкретные сроки хранения будут согласованы перед включением загрузки файлов.
