# Версия 22: сотрудники, бригады и табель в рабочей базе

## Рабочий режим `crm.eftsip.ru`

- список сотрудников и бригад загружается из MySQL после входа;
- добавление и редактирование сотрудника записывает данные и выбранный аватар на сервер;
- состав бригады, бригадир и контакты сохраняются транзакционно;
- табель загружается отдельно для выбранного месяца;
- быстрые отметки и подробная форма записывают изменения через API;
- ставки и авансы сохраняются только при наличии финансовых прав;
- ошибки сервера отображаются в форме или уведомлении и не закрывают введённые данные.

## Демонстрационный режим

GitHub Pages продолжает использовать локальные примеры и `localStorage`, чтобы интерфейс можно было изучать без аккаунта и без доступа к рабочим данным.
