# Версия 21: серверный контур сотрудников и табеля

## Подготовлено до запуска базы

- API клиента для списка и сохранения сотрудников, табеля и зарплатной ведомости;
- сохранение выбранного аватара сотрудника в MySQL;
- серверные права на просмотр и изменение сотрудников;
- отдельные права на табель и финансовые данные;
- финансовая часть в рабочем режиме открывается по роли пользователя, а не по общему PIN коду;
- PIN `911` остаётся только в публичной демоверсии для показа интерфейса.

## После выпуска HTTPS

Одноразовый установщик создаст схему уже с полем аватара. Затем интерфейс сотрудников и табеля будет переведён с демонстрационных данных на подготовленные API методы.
