# ЭФТ CRM — версия 11

## Карточка клиента и заявки

- Нажатие на клиента или заявку открывает отдельный рабочий экран с прямой ссылкой вида `#client/<id>`.
- На экране собраны контакты, объект, ответственный менеджер, этап заявки, прогресс, примечания, производство и связанные задачи.
- Общение можно фиксировать прямо в карточке: звонок, мессенджер, письмо, встреча или заметка.
- Следующее действие выбирается из готового списка и получает дату и время. Новый вариант действия можно добавить в карточке; он сохраняется в общем справочнике.
- Стартовый справочник покрывает первичный контакт, сбор исходных данных, расчёт, коммерческое предложение, смету, договор, оплату, выезд, проектирование, производство, монтаж и контроль этапа.
- В карточку можно прикрепить фотографии, PDF, документы, текстовые файлы и экспорт писем. В демоверсии файл ограничен 800 КБ и хранится только в localStorage этого браузера.

## Закупки и склад

- Материалы склада и общего прайса показываются одним прокручиваемым списком.
- Заголовок таблицы остаётся видимым при прокрутке. Поиск и фильтр категории работают по всему списку.
- Для длинного каталога используется отложенная отрисовка невидимых строк браузером.

## Границы версии

Версия остаётся публичной локальной демонстрацией без серверной базы и авторизации. Вложения не передаются на сервер и недоступны с другого устройства. Для производственного хранения файлов, переписок и персональных данных нужен закрытый сервер, роли доступа, резервное копирование и журнал действий.
