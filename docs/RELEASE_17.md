# Версия 17

## Быстрое заполнение табеля

- добавлены быстрые отметки: `+ 8 ч`, 4, 6 и 10 часов, выходной, отпуск и больничный;
- восемь рабочих часов отображаются знаком `+`, другое количество — числом;
- выходной выделяется красным, отпуск синим, больничный жёлтым;
- режим «Подробно» открывает прежнюю форму с произвольным количеством часов и примечанием.

## Зарплатная ведомость

- финансовая часть остаётся закрытой PIN-кодом `911`;
- для каждого сотрудника можно задать фиксированный аванс, значение `0` включает расчёт 30% заработанного по табелю с 1 по 25 число;
- аванс показывается к выплате 25 числа текущего месяца;
- окончательный расчёт показывается 10 числа следующего месяца как начисление за месяц за вычетом аванса;
- добавлена отдельная печатная зарплатная ведомость.

Расчёт в публичной демонстрации предварительный. Серверная версия получит роли, журнал изменений и закрытое хранение финансовых данных.
