# EFT CRM — версия 25

- Финансовая часть табеля открывается отдельным серверным PIN; начальное значение — `911`.
- Ставки, начисления, авансы и зарплатная ведомость не передаются клиенту до разблокировки.
- В настройках добавлено управление учётными записями сотрудников, логинами, паролями, ролями и активностью.
- Добавлена смена финансового PIN с проверкой текущего значения и кнопками показа пароля.
- Должности, источники заявок и поставщики/контрагенты можно пополнять непосредственно при работе.
- Добавлена наглядная таблица прав всех ролей.
