# EFT CRM — версия 26

## Меню действий для потребностей

- Кнопка с тремя точками в строке потребности открывает быстрые действия.
- Доступны этапы: «Согласовать», «Товар заказан», «Товар получен», «Отказать» и «Вернуть в заявки».
- В том же меню можно открыть полное редактирование записи.
- Новый статус «Отказано» выделяется красным и не учитывается в числе открытых потребностей.
- После действия интерфейс показывает подтверждение и сразу пересчитывает сводные показатели.

## Проверка

- Автоматические тесты: 20 из 20.
- Производственная сборка Vite выполнена без ошибок.
- В браузере проверены создание потребности, открытие меню, статусы «Товар заказан» и «Отказано».
