# EFT CRM — версия 27

## Печатные бланки и документооборот

В разделе «Закупки и склад» добавлена вкладка «Бланки» с восемью печатными формами:

- заявка на закупку;
- лист сравнения предложений поставщиков;
- приходная ведомость;
- требование-накладная на выдачу материалов;
- инвентаризационная ведомость склада;
- акт выдачи инструмента;
- акт возврата и осмотра инструмента;
- универсальный пустой лист учёта.

Инвентаризационная ведомость получает текущие учётные остатки из CRM. В карточке каждого инструмента появилась печать акта с уже заполненными названием и инвентарным номером.

Печатные формы содержат реквизиты, таблицы для ручного заполнения и места для подписей. Каждую форму можно распечатать, сохранить в PDF или скачать в CSV.
