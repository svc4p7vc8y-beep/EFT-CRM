# ЭФТ CRM — версия 28

## Темы оформления

- Добавлен переключатель оформления в верхнюю панель CRM.
- Доступны три варианта: светлый, тёмный и фирменный ЭФТ.
- Фирменная тема использует графитовый цвет и зелёный акцент логотипа.
- Тёмная тема применяется к рабочей области, таблицам, карточкам, формам, диалогам и календарям.
- Выбранная тема сохраняется отдельно для каждой учётной записи в текущем браузере.
- Печатные бланки сохраняют светлое оформление независимо от темы интерфейса.
