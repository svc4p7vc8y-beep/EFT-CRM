# ЭФТ CRM — версия 29

## Серверное рабочее пространство

- Клиенты, объекты, заявки, производственные заказы, задачи и история общения сохраняются в базе CRM на сервере.
- При первом запуске существующие данные текущего браузера один раз переносятся на сервер.
- Сохранение выполняется одной транзакцией: связанные записи не остаются в частично обновлённом состоянии.
- Добавлена проверка версии данных. Если другой сотрудник уже сохранил изменения, CRM загружает свежую версию и сообщает о конфликте.
- В схему базы добавлены производственные заказы, чек-листы, объёмы выполнения, причины блокировки и история переноса сроков.
- Локальная копия остаётся резервом для интерфейса и автономных разделов, которые будут перенесены на сервер следующими этапами.
