# EFT CRM 32

## Планирование монтажных бригад

- Недельный и месячный календарь загрузки по действующим бригадам.
- Отдельный обзор загрузки: состав, бригадир, активные и просроченные этапы.
- Быстрое назначение бригады и плановых дат прямо из очереди нераспределённых этапов.
- Предупреждение о пересечении работ одной бригады на разных объектах.
- Фильтр по бригаде, навигация по периодам и переход к текущей дате.
- График использует этапы раздела «Строительство», поэтому изменения сохраняются в общей серверной базе.
