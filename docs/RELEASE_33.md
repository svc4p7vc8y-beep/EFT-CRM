# EFT CRM · версия 33

## Что добавлено

- Задачи связываются с объектом, этапом строительства и бригадой.
- В карточке каждого строительного этапа появилась кнопка «Задача».
- Новая задача из этапа получает название, объект, этап, бригаду, ответственного и плановый срок.
- В списке и боковой карточке задач показан строительный контекст.
- Серверный обмен и MySQL-схема сохраняют новые связи.

## Проверка

- `npm test`: 23 теста пройдено.
- `npm run build`: production-сборка создана.
- Форма создания задачи проверена в локальном браузере.
