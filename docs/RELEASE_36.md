# EFT CRM 36

## Надёжное сохранение закупок и склада

- Формы материалов, потребностей, закупок, движений, поставщиков и инструмента ждут подтверждение MySQL перед закрытием.
- Сообщение об успешном сохранении появляется только после ответа сервера.
- При конфликте версии или ошибке форма остаётся открытой и показывает причину.
- После ошибки CRM загружает актуальную серверную копию, чтобы временная запись не выглядела сохранённой.
- Очередь следующих складских операций продолжает работать после исправленной ошибки.
