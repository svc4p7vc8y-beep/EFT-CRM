# EFT CRM 40

Раздел «Мои задачи» перестроен в единый диспетчер. По умолчанию новая задача создаётся без исполнителя и без срока, попадает в группу «Нужно распределить» и остаётся видимой в общем списке. Добавлены режимы «Общий список», «День», «Неделя» и «Месяц», фильтр неназначенных задач, показатели загрузки и счётчик открытых задач в боковом меню.
