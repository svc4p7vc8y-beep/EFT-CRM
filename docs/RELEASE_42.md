# EFT CRM 42

## Мои задачи

- Надпись с ответственным в строке задачи стала раскрывающимся списком сотрудников.
- Ответственного также можно поменять в боковой карточке выбранной задачи.
- Выбор «Не назначен» возвращает задачу в общий список для последующего распределения.

## Исправление сохранения

- Серверная рабочая область больше не смешивается с устаревшими локальными вложениями браузера.
- Ошибка «Некорректное вложение клиента» больше не блокирует создание и назначение задач.
