# CRM ЭФТ · версия 45

В «Центре общения» владелец и администратор могут подключить рабочий ящик через форму «Подключения». Пользователь вводит адрес и пароль внешнего приложения непосредственно на `crm.eftsip.ru`; пароль передаётся только на API CRM и сохраняется в закрытом `api/mail.local.php`. API не возвращает пароль клиенту. Файл исключён из Git и публикации, доступ к нему закрыт веб-сервером.

После сохранения настроек нажмите «Проверить почту». Синхронизация импортирует текст входящих писем за последние 30 дней; повторная синхронизация не создаёт дубликаты. Для проверки отправки ответьте на тестовое письмо из CRM.
