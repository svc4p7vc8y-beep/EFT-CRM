# CRM ЭФТ · версия 46

- Неразобранные входящие письма сгруппированы по отправителям. Поиск в Центре общения находит отправителя, тему и текст; фильтр непрочитанных действует и на эти письма.
- В «Подключениях» владелец или администратор может ввести токен нового Telegram-бота. CRM проверяет токен методом `getMe`, показывает имя бота и сохраняет токен только в закрытом `api/telegram.local.php`. Токен не возвращается браузеру и не публикуется в GitHub.
- Отправка сообщения в Telegram клиенту без привязанного чата блокируется с понятной подсказкой. Привязка чатов и приём входящих сообщений станут следующим этапом после создания бота.

Проверка почты `sale@eftsip.ru`: SMTP отправил тестовое письмо самому ящику, IMAP импортировал его в CRM, повторный импорт не создал дубликата.
