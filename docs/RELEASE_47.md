# CRM ЭФТ · версия 47

Неразобранные входящие письма рабочего ящика доступны только владельцу и администратору. Сотрудники с правом просмотра клиентов видят историю уже привязанных к объектам сообщений. Ручная синхронизация почты и привязка входящего письма также требуют права управления интеграциями.

При сохранении общего рабочего пространства менеджером скрытые письма остаются в базе данных. Ответ `workspace.save` учитывает права текущего сотрудника и не раскрывает ему закрытую очередь почты.
