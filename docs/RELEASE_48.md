# CRM ЭФТ · версия 48

В карточке клиента, заявке и списке клиентов номер телефона открывает набор вызова на устройстве. В основной карточке добавлена отдельная кнопка «Позвонить». Номера с российским префиксом 8 передаются в международном формате +7.

Звонок выполняет телефонное приложение устройства через обычную SIM-карту. Автоматическая история и запись разговоров потребуют подключения Корпоративной АТС t2.
