# CRM ЭФТ · версия 49

В Центре общения исправлена прокрутка длинной ленты писем. Неразобранные письма можно свернуть, а выбор клиента раскрывается только для нужного письма.

Почта разделена на папки «Входящие», «Отправленные» и «Не учитывать». Отправленные показывают письма, отправленные из CRM. Письмо без клиента можно перенести в «Не учитывать» и позже вернуть во входящие. Этот статус хранится на сервере и сохраняется при обновлении страницы.
