# CRM ЭФТ · версия 50

Синхронизация рабочего ящика загружает входящие и существующие отправленные письма за последние 30 дней. Отправленные письма сопоставляются с клиентом по адресу получателя. Если клиент не найден, письмо появляется в папке «Отправленные» без привязки и его можно привязать вручную или перенести в «Не учитывать».

Повторная синхронизация не дублирует письма. Секреты почтового ящика остаются в серверной конфигурации.
