# CRM ЭФТ · версия 51

## Центр общения

- Поиск по клиенту, объекту, отправителю, теме, тексту и названию вложения.
- Массовая привязка неразобранных писем к объекту и перенос в «Не учитывать».
- Правила для новых входящих писем по отправителю или теме: привязать к объекту либо не учитывать. Правила не меняют уже импортированную почту.
- Статус сообщения, дата напоминания, фильтры «Нужно ответить» и «Срок прошёл».
- Общие шаблоны быстрых ответов с управлением для администратора.
- Создание задачи из письма с заполненным объектом, темой и выдержкой.
- Список файлов переписки и загрузка вложений из входящих писем поддерживаемых типов. Вложения исходящих писем уже хранились на сервере.
- Обнаружение клиентов с одинаковым адресом почты и подтверждаемое объединение их объектов и истории.
- Локальные браузерные уведомления о новых входящих сообщениях при открытой CRM после явного разрешения пользователя.
- Журнал звонков доступен в фильтре каналов. Запись итогов звонка уже была доступна.
- Помощник показывает краткую выдержку из диалога и создаёт шаблонный черновик ответа. Черновик проверяется сотрудником перед отправкой.
- Счётчики писем без ответа, просроченных напоминаний и среднее время ответа по электронной почте.

## Telegram

После создания бота администратор вводит токен в настройках Центра общения. CRM проверяет бота, регистрирует webhook и выдаёт для каждого объекта одноразовую ссылку на привязку чата. Ссылка действует 24 часа. После открытия ссылки клиентом входящие текстовые сообщения попадают в историю объекта; из CRM можно ответить через бота. До создания бота этот сценарий проверить на реальном чате нельзя.

## Внешние зависимости

- WhatsApp и MAX требуют действующих API-доступов соответствующих платформ.
- Автоматический журнал звонков t2, записи и расшифровки требуют корпоративную АТС. При обычной SIM работает только набор номера и ручная запись итога звонка.
- Помощник версии 51 работает по шаблону без внешней модели; полноценное AI-резюмирование потребует отдельного API и правил обработки персональных данных.
