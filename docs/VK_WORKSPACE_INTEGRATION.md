# Интеграция VK WorkSpace

Проверено по официальной документации VK WorkSpace 23.09.2026.

## Возможности базового тарифа

- интеграция по API;
- работа почты через сторонние клиенты по IMAP/POP3;
- общие почтовые ящики;
- календарь;
- Диск и работа с документами через WebDAV;
- до 300 пользователей и 150 ГБ облачного пространства на пользователя.

SSO, расширенные групповые политики и аудит VK WorkSpace относятся к расширенному тарифу. Для первого запуска CRM они не обязательны: CRM получит собственные роли и журнал действий.

## Порядок подключения

1. Создать общий ящик CRM, например `crm@eftsip.ru` или использовать согласованный ящик продаж.
2. Подключить чтение и отправку почты на сервере CRM. Пароль приложения хранить только в закрытом конфигурационном файле Beget.
3. Связывать письмо с клиентом и объектом по адресу, ручному выбору и внешнему ключу письма.
4. Подключить Диск через WebDAV для рабочих документов, не открывая публичные ссылки по умолчанию.
5. После проверки доступного API подключить календарные события и уведомления.

В `crm_integration_accounts` хранятся только состояние и несекретные настройки интеграции. Пароли, токены и ключи в базу демонстрационной версии и публичный GitHub не добавляются.
